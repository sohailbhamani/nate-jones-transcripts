# Fable 5.1 is quietly 45% cheaper to run #AI #Fable5 #Anthropic #APIbuilders #tokens

Now, we need to talk about efficiency because this is where the Fable story gets easy to overstate and I want to be really clear. Fable 5.1 cost 10 bucks per million input tokens and 50 bucks per million output tokens if you're on API billing. That's the same base price as Fable 5. Cash reads though dropped a ton from a dollar to 25 cents per million tokens and if you're an enterprise and you're using the cash, that's a huge deal. Anthropic is estimating right now that a typical workload costs about 25% less than Fable 5 and that highly agentic work which uses cash a lot may cost about 45% less.
